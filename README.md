# Personal Portfolio – Soumojit Jati

A personal portfolio website showcasing my skills, projects, achievements, and journey as an aspiring software developer.

## 🌐 Overview

This portfolio is designed to provide a glimpse into my technical background, development experience, and projects. It features a modern, colorful interface with responsive layouts and smooth animations.

## ✨ Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Hero Section:** Introduction with profile photo and animated text.
- **About Me:** Overview of my background and interests.
- **Skills Section:** Highlights my technical skills and tools.
- **Projects Showcase:** Displays selected projects with descriptions and technology stacks.
- **Achievements:** Highlights learning experiences and accomplishments.
- **Contact Section:** Provides ways to connect with me.
- **Smooth Navigation:** Easy navigation between different sections.

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS v4
- HTML5
- CSS3
- Vite
- Git & GitHub

## 🚀 Featured Projects

A full-stack web application designed to help students report and find lost or found items on campus.

### 2. Tic-Tac-Toe
